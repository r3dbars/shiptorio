Design reference for the Shiptorio UI: Justin's "Feedback Factory" canvas https://claude.ai/artifact/HtWP6pHDcYn9TSByR6UJcn (Justin calls it "the shiptorio one"). Most relevant artboards: `Belts.dc.html` (Factorio look: belts, machines, "Review chest" = PRs waiting on you, "Load into rocket" = merge, rocket = release, research bar), `Main.dc.html` (factory floor lanes: Incoming → Sorted by Claude → Machines → Shipping), `Stack.dc.html` (verifier lanes, escalations, morning review).

Factorio palette used in Belts: ground #1B1A18, panels #313031 w/ 2px #111 border + inset #4A4847, title text #FFE6C0, accent orange #FFA200, green #6CCB3C, red #E04B3A, concrete #4B4944 grid #34322E, grass #5F6630, font Titillium Web.
