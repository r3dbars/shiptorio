Don't trust it. Prove it.

Agent output is untrusted until it shows evidence. "Done" means the bug is gone in the real app, not that the code compiles or the agent said so. And you only scale up (more machines, more autonomy) once the checks are trustworthy.

Fix each problem at the strongest layer that can catch it. Layer 1 is strongest: it never forgets and never gets skipped. Your own review is the last net, not the first.

Promote a check. Same failure twice? Spark offers to move it up a layer. A review comment that keeps coming back becomes a lint rule. A proof that keeps failing on /checkout becomes a test turret. The gauntlet gets stronger every time it catches something.

Research · inspection tech

Add more checks

New stations are research. You spend science packs (the PRs you've shipped) to unlock them, and Spark tells you which one would have caught last week's misses.

Test turret

Writes tests around a district. Catches regressions.

Visual diff camera

Screenshots pages before and after. Catches broken layouts.

Security sentry

Looks for leaked secrets, auth holes, unsafe input.

Perf gauge

Load time and bundle size budget. Catches slow.

Canary tower

Ships to 5% first. Rolls back if errors climb.

Arena

Two machines build the same fix. A judge keeps the better one.

The pull

Why you keep playing

It plays like a factory game you can't put down. The difference is that every point is a real thing that happened to your product.

There's always one bottleneck

It glows on the map with one next move. Fix it, and the next one shows up.

Rockets

Every merge is a launch. Countdown, vapor, liftoff, and Sentry goes quiet.

Catches are trophies

Each station counts the bugs it stopped before they shipped. That number only goes up.

New stuff to unlock

Stations, machines, power plants. Research is always one or two rockets away.

Spark earns autonomy

Play clean and Spark runs more on its own: Advisor, Floor, Build, launch permits, Lights out.

Every number is real

Users unblocked, customers answered, checkouts completed. Ship bad work and the score drops hard.

Later · more factories

Same loop, more islands

We start with the repo. The same ore → power → gauntlet → rocket loop works for the rest of the business. Each one is an add-on island with its own ore and its own checks.

Locked calls

Which stations ship for the Nov 4 demo?

CI inspector, verify bay, AI review, merge gate. Orbit watch as a Sentry check if there's time. Research tree shown, one unlock on camera.

Locked: those four. The verify bay is the thing nobody else has, so it's the demo moment.

Where do fails go?

Back to Spark at the start of the line, carrying a scar tag (what failed, the evidence). Spark re-plans. Third strike comes to you.

Locked: Spark, not straight back to the builder. That's how the loop learns.

Who runs the review?

A different model than the builder: Claude builds, Codex reviews, and the reverse. With one sign-in, a fresh session with a hostile reviewer loadout.

Locked: different model family when both are plugged in. It costs power, so it shows on the meter.

Can players remove a station?

Per district, yes. But launch permits need the stations their risk calls for, so cutting checks caps autonomy. The merge gate can't be removed without a permit.

Locked: allowed, with the trust cost shown.
